08
Recommendation Models
Four content-based approaches implemented and compared
TF-IDF
Sparse
Builds weighted text from genres, tags, title & description. Computes cosine similarity between sparse vectors.
BM25F
Field-Weighted
Scores each field (genres, tags, title, description) separately with different weights before combining.
Embeddings
Dense
Encodes anime text into dense semantic vectors using MiniLM & BGE. Captures meaning beyond exact words.
Hybrid ✦
Best Model
Combines BM25F + TF-IDF + Embeddings scores with genre & tag overlap as a final re-ranking signal.

Field Weighted

10
Hybrid Model
Combines all models into one final score
Hybrid
Best Model
# Weights (from config)
weights = {
  bm25f: 0.35,
  embedding: 0.30,
  tag_overlap: 0.15,
  tfidf: 0.15,
  genre_overlap: 0.05,
}

# Get scores from each model
bm25f_s = bm25f.score(query)
tfidf_s = cosine(tfidf[query], tfidf)
embed_s = cosine(bge[query], bge)
tag_s = jaccard(query.tags, all.tags)
genre_s = jaccard(query.genres, all.genres)

# Normalize each to [0, 1]
for s in [bm25f_s, tfidf_s,
          embed_s]:
  s = (s - min) / (max - min)

# Combine
final = (
  weights[bm25f] × bm25f_s +
  weights[embed] × embed_s +
  weights[tags] × tag_s +
  weights[tfidf] × tfidf_s +
  weights[genre] × genre_s
)
return top_k(final)

Why Hybrid wins
BM25F catches exact keyword matches. BGE captures semantic meaning. Tag & genre overlap adds explicit metadata signals. Each covers the other's weaknesses.
BGE vs MiniLM
BGE NDCG@3 = 0.753 vs MiniLM 0.577 — 768-dim richer representation makes a significant difference for top-ranked results.
